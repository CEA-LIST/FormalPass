How I installed and built LLVM 16 (to benefit from LLVM's automatic vectorization capabilities):


1) mkdir llvm16-source
2) cd llvm16-source/
3) git clone --depth 1 --branch llvmorg-16.0.0  https://github.com/llvm/llvm-project.git
4) cd llvm-project/
*In case clang is not installed 
5) sudo apt install clang-5.0 --install-suggests
6) cmake -S llvm -B build -G "Unix Makefiles" -DCMAKE_BUILD_TYPE=Release -DLLVM_ENABLE_PROJECTS=all -DLLVM_ENABLE_ASSERTIONS=ON

Build Type          Optimizations       Debug Info       ASSERTIONS      Best Suited For
Release             For speed           No               No              Users of LLVM and Clang
Debug               None                Yes              Yes             Developers of LLVM
RelWithDebInfo      For speed           Yes              No              Users that also need debug
MinSizeRel          For Size            No               No              When disk space matters           


Builds with debug information can use a lot of RAM and disk space and is usually slower to run. You can improve RAM usage by using lld, see the LLVM_USE_LINKER option: Override the system’s default linker. For instance use lld with -DLLVM_USE_LINKER=lld.

7) make -C build check-llvm

8) cd build

9) make check-lld (to override the system's default linker because LLVM's lld is faster!).

10) make -j8 clang (or to build the whole compiler: make -j8) 

11) make -j8 llc
